# Specs

What must be true of the kit: the skills it ships, what each installs, and the rules a
bot or a mothership built on it must satisfy. Declarative; not how it is coded.

## Status

October 2026. Written from three running bots and one retired one. Only the
`mothership` skill's fleet sheets exist so far; the `opsbot-*` skills are being
extracted from the most mature running bot one at a time. Unknowns are marked `TK`.

| File | Covers |
| --- | --- |
| `principles.md` | The stance every bot and mothership inherits |
| `architecture.md` | TK — the kit's shape: skills, what each installs, how a bot and a mothership are composed |
| `mothership.md` | TK — the fleet sheets and the mechanic |
